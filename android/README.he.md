# אפליקציית אנדרואיד (Botwa)

אפליקציה פנימית (לא לחנות) שפותחת את פאנל Botwa במסך מלא, עם אייקון, התראות דחיפה וקיצורי דרך. טכנית זו Trusted Web Activity: הפאנל רץ במנוע של Chrome שבטלפון, כך שההתחברות, ההתראות והעדכונים זהים לפאנל ברשת, וכל עדכון של השרת מגיע לאפליקציה מיד, בלי להתקין גרסה חדשה.

## התקנה בטלפון
1. מעבירים את `app-release.apk` לטלפון (מייל, ווצאפ לעצמכם, Drive) ופותחים אותו.
2. אנדרואיד יבקש לאשר "התקנה ממקור לא ידוע" עבור האפליקציה שממנה פתחתם את הקובץ. מאשרים.
3. פותחים את Botwa. בפעם הראשונה מופיעה כתובת המערכת (ממולאת מראש). מאשרים או מתקנים, ולוחצים "כניסה".
4. מתחברים, ב"החשבון שלי" מפעילים "התראות במכשיר הזה" ושולחים התראת בדיקה.

לשינוי כתובת השרת: לחיצה ארוכה על סמל האפליקציה ← "שינוי כתובת השרת".
נדרש Chrome (או דפדפן תומך כמו Edge / Samsung Internet) מותקן בטלפון.

## מסך מלא בלי שורת כתובת
מוסיפים לקובץ `.env` בשרת את טביעת האצבע של מפתח החתימה (לא סוד) ומפעילים מחדש:
```
ANDROID_APP_SHA256=<טביעת האצבע, בפורמט AA:BB:...>
```
השרת יגיש `/.well-known/assetlinks.json`, ו-Chrome יאמת שהאפליקציה והאתר שייכים יחד. בלי זה האפליקציה עובדת, אבל עם פס כתובת דק למעלה. אם יש reverse proxy (nginx / HestiaCP) לפני המערכת, ודאו שהנתיב `/.well-known/assetlinks.json` מועבר לאפליקציה.

## בנייה מחדש (רק אם משנים שם, כתובת ברירת מחדל או גרסה)
דרוש JDK 17+ ו-Android SDK (platform 36). מפתח החתימה לא נשמר בריפו: הוא מועבר במשתני סביבה.
```bash
cd android
echo "sdk.dir=/path/to/android-sdk" > local.properties
export BOTWA_KEYSTORE=/secure/path/botwa-release.jks BOTWA_KEYSTORE_PASSWORD='...' BOTWA_KEY_ALIAS=botwa
./gradlew assembleRelease -Pbotwa.url=https://support.example.com/ -Pbotwa.versionCode=2 -Pbotwa.versionName=1.1
# הקובץ: app/build/outputs/apk/release/app-release.apk
```
**מפתח החתימה:** שמרו את קובץ ה-`.jks` והסיסמה בגיבוי מאובטח (מנהל סיסמאות). עדכון לאפליקציה מותקנת חייב להיות חתום באותו מפתח; בלעדיו צריך להסיר ולהתקין מחדש בכל טלפון. לעולם לא מעלים אותו לריפו או שולחים אותו בצ'אט.

## אבטחה
- כתובת השרת נשמרת בטלפון בלבד, ומתקבלת רק ב-https.
- האפליקציה לא שומרת סיסמאות או נתוני לקוחות: הכול בפאנל, באותה הגנה כמו בדפדפן (Passkey / אימות דו-שלבי מומלצים).
- גיבוי אוטומטי של אנדרואיד כבוי לאפליקציה.
