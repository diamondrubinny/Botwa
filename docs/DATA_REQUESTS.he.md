# נוהל: בקשות של נושאי מידע (עיון / ייצוא / מחיקה)

> ⚠️ טיוטה תפעולית. מועדי תגובה וסמכויות – לאישור משפטי ([30] ימים כברירת מחדל מוצעת).

המערכת תומכת במימוש בקשות ברמת איש קשר (פונה אחד), **למנהל מערכת בלבד**. כל פעולה נרשמת ביומן הביקורת.

1. **קבלת הבקשה** (אימייל/טלפון לפי מדיניות הפרטיות). תעדו תאריך קבלה ופרטי הפונה.
2. **אימות זהות** – לא למסור מידע לפני אימות סביר (למשל שליחת קוד בערוץ שממנו נוצרה הפנייה, או שיחה חוזרת לאותו חשבון).
3. **איתור איש הקשר**: בפאנל, שיחות ← חיפוש לפי מספר/שם ← פתיחת השיחה. מנהל מערכת רואה בתחתית השיחה את הכפתורים "ייצוא נתוני איש הקשר" ו"מחיקת איש הקשר וכל הנתונים".
4. **עיון / ייצוא**: הכפתור "ייצוא" (שקורא ל-`GET /contacts/:id/export`) מוריד קובץ JSON עם את פרטי איש הקשר, כל ההודעות ושמות הקבצים וסטטוס הסריקה. קבצי המדיה עצמם נמצאים ב-volume `media` ויימסרו ידנית בעת הצורך. העבירו את הקובץ לפונה בערוץ מאובטח.
5. **מחיקה**: הכפתור "מחיקה" (אחרי אישור; `DELETE /contacts/:id`) מוחק את איש הקשר, השיחה, ההודעות, ההערות הפנימיות והקבצים מהדיסק. בדקו קודם שאין חובת שמירה (הליך משפטי, חובה חוקית).
   - גיבויים: המידע יישאר בגיבויים קיימים עד תום מחזור הגיבוי ([14] ימים). תעדו זאת בתשובה לפונה.
   - הפונה יכול לשוב ולפנות; תיפתח שיחה חדשה.
6. **תיעוד**: רשמו במעקב הבקשות (מחוץ למערכת) – תאריך, סוג, תוצאה, מי טיפל. אל תשמרו שם את תוכן השיחה.
7. **תקלות/דליפה**: אם נחשד אירוע אבטחה, פעלו לפי נוהל האירוע של הארגון ושקלו חובת דיווח לרשות הגנת הפרטיות (דורש ייעוץ משפטי).
