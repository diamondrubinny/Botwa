# מודל שפה מקומי לניסוח תשובות הבוט

## מה זה
בהגדרות הבוט, תחת "אופן הניסוח של התשובה", בוחרים אחת משתי אפשרויות:
- **ציטוט מהמאגר (ברירת מחדל):** בלי בינה מלאכותית. הבוט מציג את הקטע הרלוונטי עם פתיח, המקור ושורת סיום.
- **מודל שפה מקומי:** מודל שרץ על השרת שלכם (Ollama) מנסח תשובה טבעית בטון נעים ומקצועי, **רק** מתוך הקטעים שנמצאו במאגר הידע.

שום מידע לא נשלח לשירות חיצוני.

## הגנות
- **מתי המודל מופעל:** רק אחרי שהחיפוש במאגר מצא התאמה בטוחה. בלי התאמה, הבוט לא עונה ולא מנחש.
- **מה המודל מקבל:** את שאלת הלקוח ואת הקטעים שנמצאו (עד 3), עם הוראות מחייבות:
  - לענות רק מתוכם.
  - לא להמציא מספרים, סעיפים, תקנים או טלפונים.
  - לענות `NO_ANSWER` כשהקטעים לא מכסים את השאלה.
- **בדיקה אחרי המודל:** כל מספר של שתי ספרות ומעלה (תקן, סעיף, שנה, טלפון, סכום) וכל קישור בתשובה חייבים להופיע בקטעים.
  - אם לא, או אם המודל לא ענה בזמן, נשלח ציטוט במקום.
- **תוספות קבועות:** מתחת לכל תשובה מצורפים תמיד המקור והערת החקיקה. הן נקבעות בקוד, לא על ידי המודל.
- **כתובת המודל:** מוגדרת רק בקובץ `.env` בשרת, ואי אפשר לשנות אותה מהפאנל.

## התקנה (על שרת עם Docker, למשל ‎`/opt/botwa`‎)
1. **בחירת גרסה:** בדקו את הגרסה העדכנית של Ollama בדף הרשמי (github.com/ollama/ollama/releases), ובחרו גרסה שפורסמה לפני שבועיים לפחות.
2. **הפעלת Ollama** באותה רשת של Botwa, בלי לפתוח פורט החוצה:
   ```bash
   cd /opt/botwa
   sudo docker run -d --name botwa-ollama --restart unless-stopped --network botwa_default \
     -v botwa_ollama:/root/.ollama ollama/ollama:<גרסה>
   sudo docker exec botwa-ollama ollama pull qwen2.5:7b-instruct
   ```
3. **הגדרת Botwa:** הוסיפו לקובץ `/opt/botwa/.env`:
   ```
   LOCAL_LLM_URL=http://botwa-ollama:11434
   LOCAL_LLM_MODEL=qwen2.5:7b-instruct
   ```
4. **הפעלה מחדש:** `sudo docker compose up -d`. אחר כך בפאנל: בוט ← מענה ממאגר הידע ← "מודל שפה מקומי". שם אמורה להופיע ההודעה "המודל המקומי ... מוכן".
5. **בדיקה:** כתבו שאלה בשדה הבדיקה ולחצו "איך הבוט יענה?".

## לפני הפעלה ללקוחות
- **איכות:** מודלים שרצים על מעבד בלבד (בלי GPU) מנסחים עברית פחות טוב ממודלי ענן, ועונים לאט: כמה שניות עד עשרות שניות לתשובה. בדקו כמה שאלות אמיתיות לפני ההפעלה.
- **בחירת מודל:**
  - `qwen2.5:3b-instruct` מהיר יותר אבל פחות איכותי.
  - מודל רב-לשוני גדול יותר יהיה איטי יותר.
  - איכות העברית של כל מודל דורשת בדיקה בפועל.
- **משאבים:** המודל המוצע תופס כ-5GB דיסק ובערך 6–8GB זיכרון כשהוא פעיל.
- **חזרה לציטוט:** אפשר לחזור לציטוט בכל רגע בלחיצה אחת. אם המודל נכבה, הבוט חוזר לציטוט מעצמו.
