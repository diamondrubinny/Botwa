# אינטגרציות: API ו-Webhooks

תפריט **אינטגרציות** (הרשאה `api.manage`, מנהל כברירת מחדל).

## מפתחות API
- מפתח עם הרשאות: **קריאה** (שיחות, הודעות, תגיות, צוות), **שליחה** (תשובה בשיחה קיימת בלבד), **ניהול** (סטטוס, שיוך, תגיות קיימות).
- המפתח מוצג פעם אחת. נשמר רק גיבוב. ביטול תופס מיד.
- הרשאה: `Authorization: Bearer bk_...`. עוגיית ההתחברות של הלוח אינה עובדת ב-API.
- אין נקודה שמאפשרת לפתוח שיחה ללקוח שלא פנה: שליחה עוברת את אותם כללים של נציג (חסימה, הסרה מרשימה, חלון תגובה, השהיית חירום).
- הגבלת קצב לכל מפתח. שימושים נרשמים ביומן הביקורת.

נקודות: `GET /api/v1/conversations`, `/conversations/:id`, `/conversations/:id/messages?after_seq=`, `POST /conversations/:id/messages|status|assign|tags`, `GET /tags`, `GET /users`. דוגמאות בלשונית "תיעוד" שבלוח.

## Webhooks
- אירועים: הודעה נכנסת, הודעה יוצאת, שינוי סטטוס, שיוך.
- כל אירוע נחתם: `X-Botwa-Signature: t=<זמן>,v1=<HMAC-SHA256 של "<t>.<גוף>">`. יש לבדוק חתימה וגם שהזמן עדכני.
- תור עמיד: ניסיונות חוזרים (דקה, 5 דקות, חצי שעה, שעתיים, 6 שעות, יממה), ואחרי 20 כשלונות רצופים הכתובת מושבתת. אירוע עלול להגיע יותר מפעם אחת: יש להשתמש ב-`id`.
- כתובת https ציבורית בלבד. כתובות פנימיות, localhost וכתובות הענן נחסמות, גם מול החלפת DNS ובלי מעקב אחרי הפניות.
- אפשר להוציא את טקסט ההודעות מהאירועים (נשלחים רק מזהים). טקסט שנשלח החוצה הוא מידע אישי: יש להוסיף את המערכת המקבלת למפת המידע ולמדיניות הפרטיות (בדיקה משפטית).
- שליחות נשמרות 7 ימים.
