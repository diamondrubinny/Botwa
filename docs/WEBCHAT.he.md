# ויגיט צ׳אט לאתרים

ערוץ שמטמיעים בכל אתר בשורת קוד אחת. הפניות נכנסות לאותה תיבה כמו ווצאפ וטלגרם, והבוט, תרשים הזרימה, מאגר הידע, הניתוב והדוחות עובדים גם בו. אין סיכון חסימה ואין תלות בפלטפורמה חיצונית.

## הקמה
1. **ערוצים ← ערוץ חדש ← צ׳אט באתר**, ואז **הגדרת הוויגיט וקוד ההטמעה**.
2. **אתרים מורשים**: רשמו את הכתובות שמותר להן להציג את הצ׳אט (`https://www.example.com`, או `https://*.example.com` לכל תת-דומיין). בלי רשימה הוויגיט לא יוצג באף אתר.
3. עדכנו מראה והתנהגות (כותרת, צבע, שפה, בקשת שם/אימייל/טלפון, הצהרת הסכמה, בועת הזמנה, פתיחה אוטומטית, הודעה מחוץ לשעות), ובדקו ב"תצוגה מקדימה".
4. **שמירה והפעלה**, והעתיקו את הקוד:
```html
<script src="https://YOUR-SERVER/widget.js" data-key="wc_..." async></script>
```
5. הדביקו אותו לפני `</body>` בכל עמוד שבו הצ׳אט צריך להופיע.

אפשר ליצור כמה ערוצי צ׳אט (אחד לכל אתר, עם עיצוב והרשאות משלו). הצ׳אט עובד בנייד, ב-RTL ובמקלדת (נבדק עם בדיקות נגישות אוטומטיות).

## שליטה מהאתר (JavaScript)
```js
BotwaChat.open(); BotwaChat.close(); BotwaChat.toggle(); BotwaChat.destroy();
BotwaChat.on('newMessage', e => console.log('לא נקראו:', e.unread)); // גם: ready, open, close, conversationStarted
```

## זיהוי לקוח מחובר (אופציונלי)
כדי שלקוח מחובר יראה את אותה שיחה מכל מכשיר, שרת האתר שלכם מחשב חתימה ומעביר אותה לוויגיט:
```js
// בשרת האתר (Node). ב-PHP: hash_hmac('sha256', $customerId, $secret)
const signature = crypto.createHmac('sha256', SECRET).update(String(customer.id)).digest('hex');
// בעמוד:
window.botwaChatIdentity = { id: String(customer.id), signature, name: customer.name, email: customer.email };
```
`SECRET` נוצר ב"זיהוי לקוח מחובר ← יצירת סוד חדש" ומוצג פעם אחת. **לעולם אל תחשבו את החתימה בדפדפן.** בלי חתימה תקפה השם והאימייל הם רק מילוי מראש, והמזהה לא נחשב מאומת.

## אבטחה
- **מי יכול להטמיע:** הצ׳אט רץ במסגרת (iframe) מהשרת שלכם. הדפדפן עצמו חוסם הטמעה באתר שאינו ברשימה (CSP `frame-ancestors`), וגם קריאת ההגדרות נחסמת לאתרים לא מורשים (CORS). אתר לא מורשה לא יראה אפילו כפתור.
- **בידוד:** האתר המארח לא יכול לקרוא את תוכן הצ׳אט, והצ׳אט לא יכול לקרוא את האתר. הקוד שבאתר מצייר רק כפתור.
- **גולשים אנונימיים:** האישור היחיד הוא אסימון אקראי שנשמר בדפדפן של הגולש (ומאוחסן אצלנו כגיבוב). אין עוגיות צד שלישי ואין מעקב.
- **הגנות:** הגבלת קצב לפי כתובת ולפי גולש, תקרת סשנים חדשים לשעה, שדה פיתיון נגד בוטים, הגבלת אורך, תצוגת טקסט בלבד (בלי HTML) עם קישורי http/https בלבד, ואין העלאת קבצים.
- **סוד הזיהוי** מוצפן במסד הנתונים, ולא נחשף שוב אחרי היצירה.

## פרטיות
- הגולש מזין שם/אימייל/טלפון לפי ההגדרה, וההודעות נשמרות בשיחה (כמו בשאר הערוצים, תחת מדיניות השמירה). אימייל וטלפון נרשמים כהערה פנימית.
- הצהרת הסכמה מותאמת אישית לפני תחילת שיחה, והאישור נרשם. **הניסוח, וההכרח בהסכמה, דורשים בדיקה משפטית** (פרטיות בישראל, GDPR אם יש גולשים מאירופה).
- אסימון הגולש נשמר ב-localStorage של הצ׳אט, ופועל רק לצורך השיחה. בדפדפנים שמפרידים אחסון של מסגרות צד שלישי הוא יישמר נפרד לכל אתר מארח. נקודה זו נחוצה במדיניות העוגיות/האחסון של האתר. דורש בדיקה משפטית.
- רשומות גולשים שלא היו פעילים 90 ימים נמחקות אוטומטית.

## מגבלות
- אין העלאת קבצים מהגולש, ואין אינדיקציה "הנציג מקליד".
- שיחה מתעדכנת בהמתנה ארוכה (long polling) ולא ב-WebSocket; הודעת נציג מגיעה בתוך שניות.
- לא נבדק בדפדפן Safari/iOS אמיתי (נבדק ב-Chromium). בדקו לפני העלייה לאוויר.
