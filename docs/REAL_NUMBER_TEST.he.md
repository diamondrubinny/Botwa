# בדיקה עם המספר העסקי האמיתי (ווצאפ רשמי)

כל מה שקשור ל-Meta נבדק עד עכשיו רק מול תשובות מדומות. הבדיקה הזו לוקחת כ-15–20 דקות, ומאמתת את השרשרת המלאה מול Meta.
צריך: טלפון פרטי עם ווצאפ (לא המספר העסקי), גישת מנהל לפאנל, והרשאה לפתוח את לוח הבקרה של האפליקציה ב-Meta.

## 0. לפני שמתחילים
- [ ] העדכון האחרון הותקן (bootstrap), והשרת עלה: `docker compose ps` מראה server במצב healthy.
- [ ] בקובץ `.env` בשרת: אם יש `WHATSAPP_GRAPH_VERSION`, הוא `v25.0` או חדש ממנו. אם השורה לא קיימת, ברירת המחדל היא v25.0.
- [ ] `docker compose exec server ffmpeg -version` מחזיר גרסה. בלעדיו לא יישלחו GIF בערוץ הרשמי.
- [ ] בכרטיס הערוץ הרשמי: הסטטוס "מחובר", ו"הגדרת הערוץ הרשמי" מראה שה-Webhook קיבל משהו לאחרונה.

## 1. הודעה נכנסת ובוט
- [ ] מהטלפון הפרטי: "שלום". מצופה: תוך כמה שניות מגיעה הודעת הפתיחה של בטי ("שלום, כאן בטי מיחידת הבטיחות 👋…"), ואחריה GIF "שלום!".
- [ ] משלימים הזדהות (שם, בניין וכו'). מצופה: "תודה <שם פרטי>! שמרתי את הפרטים…", ואחר כך תפריט הנושאים, ככפתורים או כרשימה.
- [ ] כותבים "תודה רבה". מצופה: ❤️ על ההודעה. GIF לא יגיע, כי עברו פחות מ-6 שעות מה-GIF הקודם.
- [ ] כותבים "נציג". מצופה: הודעת העברה, השיחה מופיעה בתיבה אצל נציג, והנציג מציג את עצמו ("שלום…, כאן…").

## 2. מענה של נציג
- [ ] מהפאנל: תשובה בטקסט. מצופה: מגיעה לטלפון, ובפאנל מופיע ✓✓ אחרי קריאה.
- [ ] מהפאנל: תמונה, קובץ PDF ו-GIF מהגלריה. מצופה: שלושתם מגיעים. ה-GIF מגיע כסרטון קצר בלי קול.
- [ ] רגשון על הודעת הלקוח. מצופה: מופיע בטלפון.
- [ ] בטלפון: מגיבים 👍 על תשובה של הבוט מהמאגר. מצופה: נספר במסך "למידה".

## 3. טפסים
- [ ] מהשיחה: שליחת טופס לחתימה. מצופה: קישור מגיע, קוד חד-פעמי מגיע בווצאפ, ממלאים וחותמים, וה-PDF החתום מופיע בשיחה.

## 4. שם משתמש עסקי
- [ ] ערוצים ← ווצאפ רשמי ← "שם משתמש עסקי". מצופה: מוצג השם הנוכחי, או "אין שם משתמש", בלי שגיאה.
  - אם מופיעה שגיאת הרשאה: לאסימון חסרה ההרשאה `whatsapp_business_management`, או גישה למספרי טלפון.
- [ ] "שמות ש-Meta שמרה לכם". מצופה: רשימה, או הודעה שאין.
- [ ] (רק אם רוצים שם) שומרים שם. ⚠️ כל שמירה מורידה החלפה אחת מתוך 2 ב-14 יום.
- [ ] (רשות) באפליקציה ב-Meta ← WhatsApp ← Configuration ← Webhook fields: לסמן `business_username_updates`.

## 5. מקרי קצה
- [ ] כותבים "הסתדרתי". מצופה: הפנייה נסגרת, מגיעה הודעת סגירה, ואחריה שאלת שביעות רצון. ה-GIF "יום נעים" יגיע רק אם עברו 6 שעות מה-GIF הקודם.
- [ ] כותבים "הייתה תאונה במעבדה" בשיחה חדשה. מצופה: הבוט עונה כרגיל, ו**לא** נשלח GIF.
- [ ] (אם יש לכם טלפון עם שם משתמש פעיל בווצאפ ומספר מוסתר) כותבים לעסק. מצופה: השיחה נקלטת, ושם הפרופיל או ‎@שם_המשתמש מוצג.
- [ ] מונה ההודעות החודשי בכרטיס הערוץ עלה בהתאם.

## אם משהו נכשל
שלחו לי את הסעיף שנכשל ואת הפלט של:
```
docker compose logs server --since 30m | grep -iE "cloud|send|webhook|username|gif" | tail -80
```
הלוגים לא כוללים אסימונים או סיסמאות, אבל יכולים לכלול מספרי טלפון. אל תפרסמו אותם בפומבי.
